INTRODUCCIÓN A LAS BUENAS PRÁCTICAS

Son un conjunto de medidas técnicas y hábitos diarios diseñados para proteger los sistemas, las redes y los datos personales o empresariales frente a amenazas digitales.

Protección de cuentas

Contraseñas seguras y únicas

El 81% de las brechas de seguridad se debe a contraseñas débiles o reutilizadas. Fuente: Microsoft Security Report.

Es recomendable crear contraseñas fuertes y distintas para cada cuenta, combinando letras, números y símbolos.

8 consejos para proteger tus contraseñas
  1. Utilizá frases largas: elegí frases fáciles de recordar y agregá mayúsculas, números y símbolos.
  2. Evitá datos personales: no utilices nombres, cumpleaños ni teléfonos.
  3. Combiná caracteres: incorporá mayúsculas, minúsculas, números y símbolos especiales.
  4. Usá claves largas: cuanto más extensa sea, mejor.
  5. No reutilices contraseñas: cada cuenta debe tener una clave diferente.
  6. Utilizá un gestor: almacená tus claves de forma segura.
  7. Revisá tus contraseñas: actualizalas cuando exista una sospecha de exposición.
  8. Evitá secuencias simples: no uses 12345678 ni patrones predecibles.
Proteger tus credenciales es fundamental para minimizar los riesgos de ataques digitales.

Seguridad de acceso

Autenticación multifactor (MFA)

La autenticación multifactor es un método de seguridad que requiere verificar la identidad mediante dos o más factores independientes.

¿Qué factores utiliza?
  • Algo que sabés: una contraseña o PIN.
  • Algo que tenés: un celular o token de seguridad.
  • Algo que sos: una huella dactilar o reconocimiento facial.
¿Cómo funciona?

Primero, el usuario ingresa su contraseña. Luego, el sistema solicita una segunda verificación, como un código temporal o reconocimiento biométrico.

Métodos de autenticación
1. Autenticación 2FA

Contraseña más un código enviado al teléfono.

2. Aplicaciones autenticadoras

Generan códigos temporales de acceso.

3. Biometría

Utiliza huellas dactilares o reconocimiento facial.

4. Tokens de hardware

Llaves físicas USB para verificar la identidad.

5. OTP por SMS o correo

Códigos de un solo uso para iniciar sesión.

6. Reconocimiento de dispositivos

Identifica dispositivos previamente registrados.

Beneficios de MFA
  • Reduce accesos no autorizados.
  • Protege frente al phishing.
  • Previene el robo de credenciales.
  • Genera confianza en los usuarios.
Protección de información

Actualizaciones y copias de seguridad

Las actualizaciones y las copias de seguridad son dos pilares fundamentales de la ciberseguridad para prevenir ataques, corregir vulnerabilidades y asegurar la continuidad operativa.

¿Por qué son importantes?

Nuestros dispositivos contienen información importante: fotografías, documentos, registros financieros y datos personales.

Esta información puede perderse por fallas del equipo, errores de software, virus, ransomware o desastres naturales.

¿Cómo realizar una copia de seguridad?

Una copia de seguridad permite conservar archivos importantes y recuperarlos cuando ocurre algún inconveniente.

1. Crear copias de los datos

Seleccioná los documentos y archivos que necesitás proteger.

2. Configurar respaldos automáticos

Utilizá servicios en la nube o dispositivos externos para almacenar tus archivos.

3. Guardar los respaldos de forma segura

Conservá los dispositivos de respaldo en un lugar seguro y separado.
